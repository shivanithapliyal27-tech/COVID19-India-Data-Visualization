# COVID-19 India Data Visualization

##  Data Visualization and Storytelling

This project presents an interactive Power BI dashboard analyzing COVID-19 cases, recoveries, and deaths across India.

## Dashboard Pages

### 1. COVID-19 India Overview
- Total Confirmed Cases
- Total Cured
- Total Deaths
- Active Cases
- Confirmed Cases Over Time
- Deaths Over Time
- State-wise Confirmed Cases

### 2. State-wise COVID-19 Impact
- Death Rate
- Recovery Rate
- Deaths by State/Union Territory
- Share of Deaths by State

### 3. COVID-19 Cases vs Deaths
- Confirmed Cases vs Deaths by State
- Top 10 States by Confirmed Cases
- Recovered Cases by State
- Cured Cases vs Deaths by State

## Tools Used

- Power BI
- DAX
- Microsoft CSV Dataset

## Dataset

COVID-19 India dataset containing state-wise cases, recoveries and deaths.

## Key Objective

To transform COVID-19 data into an interactive and visually understandable dashboard that highlights trends, state-wise impact, and relationships between confirmed cases, recoveries, and deaths.
